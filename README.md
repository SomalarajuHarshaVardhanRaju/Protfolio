## 🛠️ Tech Stack & Architecture

- **Frontend**: Semantic HTML5, CSS3 Custom Properties (Modern Dark-First Theme with Light/Dark Switch), Vanilla JavaScript (Zero bloated framework dependencies).
- **Interactive Visualizer**: Custom SVG Mathematical Regression & ML Simulation Engine with real-time MSE and $R^2$ calculation.
- **Design System**: Glassmorphism, subtle glowing gradients, responsive CSS Grid & Flexbox, accessible focus states, and fluid typography.
- **SEO & Metadata**: JSON-LD Person schema, Open Graph protocol, Twitter Cards, `robots.txt`, and XML `sitemap.xml`.

## 💻 Running the Project Locally

No build step or Node packages are required! You can open `index.html` directly or serve it with any local server:

### Option 1: Python HTTP Server (Recommended)
```powershell
python -m http.server 8000
```
Then navigate to: `http://localhost:8000`

### Option 2: Node.js `npx serve`
```powershell
npx serve .
```

### Option 3: Direct File Opening
Double-click `index.html` in your file explorer to open it in Chrome, Edge, or Firefox.
